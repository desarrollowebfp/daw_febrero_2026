# Escribir código legible para otras personas

El código se lee muchas más veces de las que se escribe. La persona que lo leerá mañana puede ser un compañero, o tú mismo dentro de seis meses sin recordar nada.

La claridad no es un lujo, es una responsabilidad.

## Qué hace que un código sea legible

- Nombres de variables que describen su propósito
- Funciones cortas con una única responsabilidad
- Comentarios que explican el *porqué*, no el *qué*
- Una estructura coherente en todo el proyecto

Un código claro reduce errores, facilita el mantenimiento y acelera la incorporación de nuevas personas al proyecto.
