# Maquetación con CSS: entender el modelo de cajas

Centrar un `div` deja de ser frustrante cuando comprendes cómo funciona el modelo de cajas y el flujo del documento.

CSS no es caprichoso: cada elemento se comporta según reglas predecibles una vez que las conoces.

> Antes de cambiar una propiedad al azar, pregúntate qué problema resuelve.

Herramientas modernas que simplifican la maquetación:

- `flexbox` para distribución en una dimensión
- `display: grid` para diseños bidimensionales complejos
- `gap` para espaciado consistente entre elementos
- Las herramientas de inspección del navegador para ver qué ocurre en tiempo real

Dominar estas bases convierte el CSS en algo controlable en lugar de una lotería.
