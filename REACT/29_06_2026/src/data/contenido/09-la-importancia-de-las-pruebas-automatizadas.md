# La importancia de las pruebas automatizadas

Probar manualmente cada cambio es lento y propenso a fallos. Las pruebas automatizadas verifican que el código sigue funcionando después de cada modificación.

> Un test que falla a tiempo evita un error en producción.

## Qué aportan las pruebas

1. Confianza para refactorizar sin miedo a romper algo
2. Detección temprana de errores, cuando son baratos de corregir
3. Documentación viva del comportamiento esperado del sistema
4. Una red de seguridad que crece con el proyecto

Empezar con pruebas sencillas y ampliarlas progresivamente es una inversión que se amortiza rápido.
