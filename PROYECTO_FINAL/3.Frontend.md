# Frontend

> **Guía completa del frontend**
> 

> Construimos el frontend de DoIt App paso a paso. Usamos Tailwind CSS v4 con un tema dark/orange custom, react-hook-form para todos los formularios, y la URL del backend se lee desde una variable de entorno de Vite para que local y producción funcionen sin tocar el código.
> 

## Objetivo

- ver una portada
- registrarse e iniciar sesión con validación en cliente
- guardar sesión y proteger rutas privadas
- dashboard con CRUD de tareas, filtros y ordenación
- perfil con edición de nombre, contraseña y avatar

---

## Orden de construcción

1. crear el proyecto e instalar dependencias
2. configurar Tailwind v4 + tema custom
3. crear `api.js` con variable de entorno
4. crear el contexto de autenticación
5. crear componentes base
6. crear páginas simples
7. crear páginas conectadas al backend
8. montar rutas en `main.jsx`  

---

## 1. Crear el proyecto e instalar dependencias

```bash
npm create vite@latest doitapp -- --template react

```


**Por qué estas librerías**

- `react-router-dom` → navegación entre páginas
- `react-hook-form` → formularios sin `useState` por campo, con validación declarativa
- `tailwindcss` + `@tailwindcss/vite` → estilos utility-first integrados en el pipeline de Vite

## 4. `src/services/api.js`

```jsx
// leemos la URL del backend desde la variable de entorno de Vite
// en local → http://localhost:3000/api  (del archivo .env)
// en producción → la URL de Render (configurada en Vercel)
const API_URL = import.meta.env.VITE_API_URL;

// ─── USERS ───────────────────────────────────────────────────────────────────

const registerUser = async (formData) => {
  const res = await fetch(`${API_URL}/users/register`, {
    method: "POST",
    body:   formData,  // FormData → el navegador gestiona el Content-Type multipart
  });
  return res.json();
};

const loginUser = async (data) => {
  const res = await fetch(`${API_URL}/users/login`, {
    method:  "POST",
    headers: { "Content-Type": "application/json" },
    body:    JSON.stringify(data),
  });
  return res.json();
};

const getMe = async (token) => {
  const res = await fetch(`${API_URL}/users/me`, {
    headers: { Authorization: `Bearer ${token}` },
  });
  return res.json();
};

const updateUsername = async (token, username) => {
  const res = await fetch(`${API_URL}/users/username`, {
    method:  "PUT",
    headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
    body:    JSON.stringify({ username }),
  });
  return res.json();
};

const updatePassword = async (token, currentPassword, newPassword) => {
  const res = await fetch(`${API_URL}/users/password`, {
    method:  "PUT",
    headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
    body:    JSON.stringify({ currentPassword, newPassword }),
  });
  return res.json();
};

const updateAvatar = async (token, formData) => {
  const res = await fetch(`${API_URL}/users/avatar`, {
    method:  "PUT",
    headers: { Authorization: `Bearer ${token}` },  // sin Content-Type: el navegador lo gestiona
    body:    formData,
  });
  return res.json();
};

// ─── TASKS ───────────────────────────────────────────────────────────────────

const getTasks = async (token, filters = {}) => {
  const params = new URLSearchParams();
  if (filters.status) params.append("status", filters.status);
  if (filters.date)   params.append("date",   filters.date);
  if (filters.sort)   params.append("sort",   filters.sort);

  const res = await fetch(`${API_URL}/tasks?${params.toString()}`, {
    headers: { Authorization: `Bearer ${token}` },
  });
  return res.json();
};

const createTask = async (token, taskData) => {
  const res = await fetch(`${API_URL}/tasks`, {
    method:  "POST",
    headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
    body:    JSON.stringify(taskData),
  });
  return res.json();
};

const updateTask = async (token, id, taskData) => {
  const res = await fetch(`${API_URL}/tasks/${id}`, {
    method:  "PUT",
    headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
    body:    JSON.stringify(taskData),
  });
  return res.json();
};

const deleteTask = async (token, id) => {
  const res = await fetch(`${API_URL}/tasks/${id}`, {
    method:  "DELETE",
    headers: { Authorization: `Bearer ${token}` },
  });
  return res.json();
};

export {
  registerUser, loginUser, getMe,
  updateUsername, updatePassword, updateAvatar,
  getTasks, createTask, updateTask, deleteTask,
};
```

## 5. `src/context/AuthContext.jsx`

```jsx
import { createContext, useCallback, useContext, useEffect, useState } from "react";
import { getMe } from "../services/api";

const AuthContext = createContext();

export const AuthProvider = ({ children }) => {
  const [token, setToken] = useState(localStorage.getItem("token") || "");
  const [user,  setUser]  = useState(null);

  // useCallback: loadUser se expone en el contexto y lo usan UsernameForm y AvatarForm
  // sin useCallback cambiaría de referencia en cada render y rompería los efectos
  const loadUser = useCallback(async () => {
    if (!token) { setUser(null); return; }

    const res = await getMe(token);

    // si la respuesta no tiene _id, el token no es válido o ha expirado
    // getMe devuelve el usuario (con _id) si va bien, o { message } si falla
    // comprobar _id es más robusto que comprobar una clave de error que puede variar
    if (!res._id) {
      localStorage.removeItem("token");
      setToken("");
      setUser(null);
      return;
    }

    setUser(res);
  }, [token]);

  useEffect(() => { loadUser(); }, [loadUser]);

  const login = useCallback((newToken, userData) => {
    localStorage.setItem("token", newToken);
    setToken(newToken);
    setUser(userData);
  }, []);

  const logout = useCallback(() => {
    localStorage.removeItem("token");
    setToken("");
    setUser(null);
  }, []);

  return (
    <AuthContext.Provider value={{ token, user, login, logout, loadUser }}>
      {children}
    </AuthContext.Provider>
  );
};

export const useAuth = () => useContext(AuthContext);
```

## 6. Componentes base

### 6.1 Navbar

Sin `Navbar.css` — los estilos van con clases de Tailwind. Para el enlace activo usamos la función `className` de `NavLink`.

```jsx
import { memo } from "react";
import { NavLink } from "react-router-dom";

// clases compartidas para todos los enlaces
const linkClass = "uppercase tracking-widest text-sm transition-colors";

// función que devuelve las clases según si el enlace está activo o no
const navLinkClass = ({ isActive }) =>
  `${linkClass} ${isActive ? "text-brand" : "text-muted hover:text-brand"}`;

const Navbar = memo(({ token, onLogout }) => {
  return (
    <nav className="bg-surface border-b border-border px-6 py-4">
      <ul className="flex gap-6 items-center list-none">
        <li>
          <NavLink to="/" end className={navLinkClass}>Inicio</NavLink>
        </li>

        {token ? (
          <>
            <li><NavLink to="/dashboard" className={navLinkClass}>Dashboard</NavLink></li>
            <li><NavLink to="/profile"   className={navLinkClass}>Perfil</NavLink></li>
            <li>
              <button
                onClick={onLogout}
                className="px-3 py-1.5 rounded-lg border border-dashed border-border text-muted hover:bg-surface hover:text-white uppercase tracking-widest text-sm transition-colors"
              >
                Salir
              </button>
            </li>
          </>
        ) : (
          <>
            <li><NavLink to="/login"    className={navLinkClass}>Login</NavLink></li>
            <li><NavLink to="/register" className={navLinkClass}>Registro</NavLink></li>
          </>
        )}
      </ul>
    </nav>
  );
});

Navbar.displayName = "Navbar";
export default Navbar;
```

**Por qué `end` en el enlace a "/"**

Sin `end`, el enlace a `/` aparecería siempre activo porque `/dashboard` también empieza por `/`. Con `end` solo se activa cuando la ruta es exactamente `/`.

### 6.2 ProtectedRoute

```jsx
import { Navigate, Outlet } from "react-router-dom";
import { useAuth } from "../context/AuthContext";

const ProtectedRoute = () => {
  const { token } = useAuth();
  // replace evita que la ruta protegida quede en el historial del navegador
  if (!token) return <Navigate to="/login" replace />;
  return <Outlet />;
};

export default ProtectedRoute;
```

### 6.4 TaskForm — con react-hook-form

```jsx
import { memo, useEffect } from "react";
import { useForm } from "react-hook-form";

// clases reutilizables
const inputClass =
  "w-full px-3 py-2 rounded-lg bg-input border border-border text-white placeholder:text-muted focus:outline-none focus:border-brand transition-colors";
const errorClass = "text-error text-xs mt-1";
const btnPrimary =
  "px-4 py-2 rounded-lg bg-brand hover:bg-brand-dark text-white uppercase tracking-widest text-sm font-medium transition-colors";
const btnOutline =
  "px-4 py-2 rounded-lg border border-dashed border-border text-muted hover:bg-surface uppercase tracking-widest text-sm transition-colors";

const TaskForm = memo(({ onSubmitTask, taskToEdit, clearTaskToEdit }) => {
  const {
    register,
    handleSubmit,
    formState: { errors },
    reset,
    setValue,
  } = useForm({ defaultValues: { title: "", date: "", status: "pending" } });

  // cuando taskToEdit cambia, rellenamos el formulario con sus datos
  useEffect(() => {
    if (taskToEdit) {
      setValue("title",  taskToEdit.title);
      setValue("date",   taskToEdit.date?.slice(0, 10)); // "2026-04-14T..." → "2026-04-14"
      setValue("status", taskToEdit.status);
    }
  }, [taskToEdit, setValue]);

  const onSubmit = (data) => {
    onSubmitTask(data);
    reset();
  };

  const handleCancel = () => {
    clearTaskToEdit();
    reset();
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)} className="flex flex-col gap-3 w-full max-w-sm">
      <div>
        <input
          type="text"
          placeholder="Título de la tarea"
          className={inputClass}
          {...register("title", {
            required:  "El título es obligatorio",
            minLength: { value: 3, message: "Mínimo 3 caracteres" },
          })}
        />
        {errors.title && <p className={errorClass}>{errors.title.message}</p>}
      </div>

      <div>
        <input
          type="date"
          className={inputClass}
          {...register("date", { required: "La fecha es obligatoria" })}
        />
        {errors.date && <p className={errorClass}>{errors.date.message}</p>}
      </div>

      <select className={inputClass} {...register("status")}>
        <option value="pending">Pendiente</option>
        <option value="completed">Completada</option>
      </select>

      <button type="submit" className={btnPrimary}>
        {taskToEdit ? "Guardar cambios" : "Crear tarea"}
      </button>

      {taskToEdit && (
        <button type="button" onClick={handleCancel} className={btnOutline}>
          Cancelar edición
        </button>
      )}
    </form>
  );
});

TaskForm.displayName = "TaskForm";
export default TaskForm;
```

## 8. Páginas conectadas al backend

### 8.1 Register

```jsx
import { useForm } from "react-hook-form";
import { useNavigate } from "react-router-dom";
import { registerUser } from "../services/api";

const inputClass  = "w-full px-3 py-2 rounded-lg bg-input border border-border text-white placeholder:text-muted focus:outline-none focus:border-brand transition-colors";
const errorClass  = "text-error text-xs mt-1";
const btnPrimary  = "w-full px-4 py-2.5 rounded-lg bg-brand hover:bg-brand-dark text-white uppercase tracking-widest text-sm font-medium transition-colors";

const Register = () => {
  const navigate = useNavigate();
  const { register, handleSubmit, formState: { errors }, setError } = useForm();

  const onSubmit = async (data) => {
    const formData = new FormData();
    formData.append("username", data.username);
    formData.append("email",    data.email);
    formData.append("password", data.password);
    // data.avatar es un FileList; si no se seleccionó ninguno el backend usa el placeholder
    if (data.avatar?.[0]) formData.append("avatar", data.avatar[0]);

    const res = await registerUser(formData);

    if (res.error) {
      setError("root", { message: res.error });
      return;
    }

    navigate("/login");
  };

  return (
    <section className="flex flex-col items-center justify-center min-h-[80vh] px-4">
      <div className="w-full max-w-sm bg-surface rounded-2xl p-8 border border-border">
        <h1 className="text-brand text-2xl font-bold uppercase tracking-widest text-center mb-6">
          Crear cuenta
        </h1>

        <form onSubmit={handleSubmit(onSubmit)} className="flex flex-col gap-4">
          <div>
            <input type="text" placeholder="Username" className={inputClass}
              {...register("username", {
                required:  "El username es obligatorio",
                minLength: { value: 3, message: "Mínimo 3 caracteres" },
              })}
            />
            {errors.username && <p className={errorClass}>{errors.username.message}</p>}
          </div>

          <div>
            <input type="email" placeholder="Email" className={inputClass}
              {...register("email", {
                required: "El email es obligatorio",
                pattern:  { value: /^[^\s@]+@[^\s@]+\.[^\s@]+$/, message: "Email no válido" },
              })}
            />
            {errors.email && <p className={errorClass}>{errors.email.message}</p>}
          </div>

          <div>
            <input type="password" placeholder="Contraseña" className={inputClass}
              {...register("password", {
                required:  "La contraseña es obligatoria",
                minLength: { value: 8, message: "Mínimo 8 caracteres" },
              })}
            />
            {errors.password && <p className={errorClass}>{errors.password.message}</p>}
          </div>

          <div>
            <label className="text-muted text-sm block mb-1">Avatar (opcional)</label>
            <input type="file" accept="image/*" className={`${inputClass} file:mr-3 file:text-muted file:bg-transparent file:border-0`}
              {...register("avatar")}
            />
          </div>

          <button type="submit" className={btnPrimary}>Registrarse</button>

          {errors.root && <p className={`${errorClass} text-center`}>{errors.root.message}</p>}
        </form>
      </div>
    </section>
  );
};

export default Register;
```

### 8.3 Dashboard

```jsx
import { useCallback, useEffect, useState } from "react";
import { useAuth } from "../context/AuthContext";
import { getTasks, createTask, updateTask, deleteTask } from "../services/api";
import TaskForm    from "../components/TaskForm";
import TaskFilters from "../components/TaskFilters";
import TaskList    from "../components/TaskList";

const Dashboard = () => {
  const { token, user } = useAuth();
  const [tasks,      setTasks]      = useState([]);
  const [taskToEdit, setTaskToEdit] = useState(null);
  const [filters,    setFilters]    = useState({ status: "", date: "", sort: "" });

  const loadTasks = useCallback(async () => {
    const res = await getTasks(token, filters);
    // el backend devuelve el array directamente; || [] protege si llega undefined
    setTasks(res || []);
  }, [token, filters]);

  useEffect(() => { loadTasks(); }, [loadTasks]);

  const handleSubmitTask = useCallback(async (formData) => {
    if (taskToEdit) {
      await updateTask(token, taskToEdit._id, formData);
      setTaskToEdit(null);
    } else {
      await createTask(token, formData);
    }
    loadTasks();
  }, [token, taskToEdit, loadTasks]);

  const handleDeleteTask = useCallback(async (id) => {
    await deleteTask(token, id);
    loadTasks();
  }, [token, loadTasks]);

  const clearTaskToEdit = useCallback(() => setTaskToEdit(null), []);

  return (
    <section className="flex flex-col items-center gap-8 px-4 py-10 max-w-5xl mx-auto w-full">
      <div className="text-center">
        <h1 className="text-brand text-3xl font-bold uppercase tracking-widest">Dashboard</h1>
        <p className="text-muted mt-1">Hola, {user?.username}</p>
      </div>

      <TaskForm
        onSubmitTask={handleSubmitTask}
        taskToEdit={taskToEdit}
        clearTaskToEdit={clearTaskToEdit}
      />

      <TaskFilters filters={filters} setFilters={setFilters} />

      <TaskList tasks={tasks} onEdit={setTaskToEdit} onDelete={handleDeleteTask} />
    </section>
  );
};
```

#### PasswordForm

Gana un campo de **confirmación de contraseña** validado en el cliente con `watch` + `validate`. El backend no necesita cambios.

```jsx
import { useForm } from "react-hook-form";
import { updatePassword } from "../services/api";
import { useAuth }        from "../context/AuthContext";

const inputClass = "w-full px-3 py-2 rounded-lg bg-input border border-border text-white placeholder:text-muted focus:outline-none focus:border-brand transition-colors";

  const newPassword = watch("newPassword");

    // el backend devuelve { error } tanto para campos vacíos como para contraseña incorrecta
    if (res.error) {
      setError("root", { message: res.error });
      return;
    }

    onMessage(res.message);
    reset();

          {...register("currentPassword", { required: "Introduce tu contraseña actual" })}
        />
        {errors.currentPassword && <p className={errorClass}>{errors.currentPassword.message}</p>}
      </div>

      <div>
        <input type="password" placeholder="Contraseña nueva" className={inputClass}
          {...register("newPassword", {
            required:  "Introduce la nueva contraseña",
            minLength: { value: 8, message: "Mínimo 8 caracteres" },
          })}
        />
        {errors.newPassword && <p className={errorClass}>{errors.newPassword.message}</p>}
      </div>

      <div>
        <input type="password" placeholder="Confirmar contraseña nueva" className={inputClass}

            required: "Confirma la nueva contraseña",
            validate: (value) => value === newPassword || "Las contraseñas no coinciden",
          })}
        />
        {errors.confirmPassword && <p className={errorClass}>{errors.confirmPassword.message}</p>}
      </div>

      <button type="submit" className={btnClass}>Guardar contraseña</button>
```

## 11. Flujo completo de la aplicación

1. el usuario entra en la portada (Home)
2. se registra — RHF valida en cliente; si no hay avatar, el backend pone el placeholder
3. inicia sesión — el token se guarda en `localStorage`
4. `loadUser` carga el perfil desde el backend
5. entra al dashboard — puede crear, editar, borrar, filtrar y ordenar tareas
6. en el perfil puede cambiar nombre, contraseña (con confirmación) y avatar
7. al cambiar el avatar, el backend borra el antiguo de Cloudinary automáticamente
8. `loadUser` se llama tras cambiar nombre o avatar — la UI refleja el cambio sin recargar

## Resumen técnico

**Backend**

- Node.js + Express con estructura modular: `config`, `middlewares`, `models`, `controllers`, `routes`, `utils`
- MongoDB + Mongoose con dos colecciones: `users` y `tasks`
- JWT para autenticación, bcrypt para contraseñas
- Cloudinary para avatares: sube a `doitusers`, elimina el anterior al actualizar
- Manejo centralizado de errores: errores esperados responden directamente con `error` o `message`; errores inesperados van a `utils/errorHandler` vía `next(error)`
- CORS configurable vía `FRONTEND_URL` en el `.env`

**Frontend**

- React 19 + Vite con nombre de proyecto `doitapp`
- React Router 7: rutas públicas y privadas con `ProtectedRoute` + `Outlet`
- react-hook-form en todos los formularios: sin `useState` por campo, validación declarativa en `register()`, errores del backend en `setError("root")`
- Tailwind CSS v4 con `@tailwindcss/vite`: tema custom definido en `@theme` con colores `brand`, `surface`, `input`, `muted`, `error`
- `AuthContext` expone `loadUser` para recargar el usuario sin recargar la página
- URL del backend en `import.meta.env.VITE_API_URL` (`.env` en local, Vercel en producción)
- Memoización con `memo` y `useCallback` en componentes y handlers
- Tests con Vitest + Testing Library para `TaskCard`, `TaskList`, `TaskForm` y `TaskFilters`

**Despliegue**

- Backend en Render (Node, Free plan)
- Frontend en Vercel con `vercel.json` para que React Router funcione al recargar
